# AIM 案件ブレイン

動画編集者のための案件獲得ツール（AIM Creators College）。

1. **営業先を選ぶ**：Indeed・クラウドワークス・ランサーズの案件から、営業したい相手だけを残す
2. **動画を分析**：相手の動画・依頼主が指定した参考動画の文字起こしを貼り、秒数つきで「直す点／再現する点」を出す
3. **営業文をつくる**：分析と募集要項から、3パターンの営業文を作って送信前チェックをかける

- 入力したプロフィール・分析・営業文は、使う人のブラウザ（localStorage）の中だけに保存されます。
- Claude は2通りで使えます。①自分の APIキー（Claude＝Anthropic、または Codex＝OpenAI）を登録して、ボタン1つで実行（キーはブラウザ内だけに保存し、api.anthropic.com／api.openai.com への呼び出しにだけ使う。利用料は本人のアカウントに請求。OpenAI はキーで使えるモデル一覧から選ぶ）②指示文をコピーして、自分の Claude のチャットに貼る（キー不要）。
- 応募・送信は代行しません。各サイトは自動操作を規約で禁止しています。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面 |
| `app.js` | 動き |
| `jobs.json` | 案件リスト（毎日朝6時に自動更新。手で編集しない） |
| `curated.json` | 手で中身を確認した案件（Indeed など）。ここを編集する |
| `update_jobs.py` | クラウドワークス・ランサーズの新着を取得して `curated.json` と合体し、`jobs.json` を作る |
| `.github/workflows/update-jobs.yml` | 上のスクリプトを毎日動かす設定（Actions タブから手動実行も可） |
