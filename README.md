# AIM 案件ブレイン

動画編集者のための案件獲得ツール（AIM Creators College）。

1. **営業先を選ぶ**：Indeed・クラウドワークス・ランサーズの案件から、営業したい相手だけを残す
2. **動画を分析**：相手の動画・依頼主が指定した参考動画の文字起こしを貼り、秒数つきで「直す点／再現する点」を出す
3. **営業文をつくる**：分析と募集要項から、3パターンの営業文を作って送信前チェックをかける

- 入力したプロフィール・分析・営業文は、使う人のブラウザ（localStorage）の中だけに保存されます。
- Claude は「指示文をコピーして、自分の Claude に貼る」形で使います。このサイトは Claude にもどこにも接続しません。
- 応募・送信は代行しません。各サイトは自動操作を規約で禁止しています。
